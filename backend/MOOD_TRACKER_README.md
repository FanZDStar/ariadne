# 心情晴雨表功能说明

## 功能概述

将人际智慧成长档案中的"学习进度"替换为"心情晴雨表"，用户可以每天为自己的心情打分（1-5 档）。

## 实现功能

1. **心情打分**: 5 个档位的心情评级（1 档最差，5 档最好）
2. **7 天表格**: 简约的表格显示最近 7 天的心情记录
3. **数据存储**: 每天只能记录一次心情，支持更新

## 数据库设计

**表名**: `mood_tracker`

- `id`: 主键
- `user_id`: 用户 ID（外键）
- `mood_date`: 记录日期
- `mood_level`: 心情档位（1-5）
- `created_at`: 创建时间
- `updated_at`: 更新时间

**约束**: 用户每天只能记录一次心情 (unique_user_date)

## API 接口

- `POST /mood-tracker/mood` - 记录心情
- `GET /mood-tracker/mood/weekly` - 获取 7 天数据

## 前端界面

- 简约的 5 个档位选择按钮
- 保存按钮（选择档位后显示）
- 7 天心情表格（日期 + 档位）

## 部署步骤

1. 执行 `backend/scripts/create_mood_table.sql` 创建数据库表
2. 重启后端服务加载新模型和 API
3. 前端已完成修改，直接使用

## 使用方式

1. 点击 1-5 任意档位按钮选择今天的心情
2. 点击"保存心情"按钮保存
3. 查看下方表格了解最近 7 天的心情变化
