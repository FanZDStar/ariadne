# 念念有声小人 Lottie 动画系统使用指南

```

├── 1/                    # 第一个小人（默认小人）

│   │   └── data.json    # Lottie动画数据
│   ├── 2/               # 第二个动作
│   │   └── data.json
│   └── 3/               # 第三个动作
│       └── data.json
├── 2/                   # 第二个小人（夏装小人）
│   ├── 1/               # 第一个动作
│   │   └── data.json
│   └── 2/               # 第二个动作
│       └── data.json
└── 3/                   # 第三个小人（冬装小人等）
    ├── 1/
    │   └── data.json
    ├── 2/
    │   └── data.json
    ├── 3/
    │   └── data.json
    └── 4/
        └── data.json
```

## 动画播放机制

### 智能文件检查

- 系统会自动检查动画文件是否存在于对应路径
- 只有实际存在的动画文件才会被播放
- 如果某个角色没有任何可用动画，将跳过动作播放
- 动画文件检查结果会被缓存，避免重复请求

### 自动播放

- 小人会每 5-10 秒随机播放一个**可用的**动作
- 播放时会从静态图片切换到 Lottie 动画
- 动画播放完毕后自动切回静态图片
- 如果没有可用动画，将保持静态状态

### 手动触发

- 用户点击小人时也会触发随机**可用**动作
- 长按小人可以打开换装界面
- 系统会从实际存在的动画文件中随机选择

### 动画规格

- **尺寸**: 130px × 156px (适配 uniapp 端)
- **格式**: Lottie JSON 格式
- **时长**: 建议 1-3 秒
- **循环**: 不循环，播放一次即结束

## 如何添加新动画

1. **创建动画文件夹**

   ```
   frontend/src/static/animations/{小人ID}/{动作编号}/
   ```

2. **放置动画文件**
   将 Lottie 导出的 JSON 文件命名为 `data.json` 并放入对应文件夹

3. **更新小人配置**
   在 `simple-mascot.vue` 的 `outfitActionGroups` 中更新对应小人的 `actionCount`

4. **测试动画**
   - 可以通过点击小人手动触发
   - 也可以等待自动播放机制

## 动画制作建议

### 尺寸要求

- 画布尺寸：130px × 156px
- 确保动画在此尺寸下清晰可见

### 动画类型建议

- **挥手动作**: 简单的手部摆动
- **跳跃动作**: 轻微的上下跳动
- **旋转动作**: 小幅度的身体旋转
- **表情变化**: 眨眼、微笑等面部动画

### 性能优化

- 保持动画简洁，避免过于复杂的效果
- 使用矢量图形，避免大量位图
- 动画时长控制在 1-3 秒内

## 故障排除

### 动画不播放

1. 检查文件路径是否正确
2. 检查 JSON 格式是否有效
3. 查看控制台是否有错误信息

### 动画显示异常

1. 检查动画尺寸是否为 130×156
2. 确认 Lottie 版本兼容性
3. 检查动画文件完整性

### 性能问题

1. 减少同时播放的动画数量
2. 优化动画复杂度
3. 检查内存使用情况

## 扩展功能

### 添加新小人

1. 在 `outfitActionGroups` 中添加新的小人配置
2. 创建对应的动画文件夹结构
3. 准备静态图片和 Lottie 动画文件

### 动作触发条件

可以根据需要添加更多触发条件：

- 特定时间触发特定动作
- 根据用户行为触发相应动作
- 结合心情状态触发对应动画

## 技术依赖

- **lottie-web**: Lottie 动画播放库
- **Vue.js**: 组件框架
- **uni-app**: 跨平台开发框架
